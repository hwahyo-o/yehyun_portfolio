# YeHyun Portfolio

React + Vite 기반의 포트폴리오 사이트입니다.

## 실행

```bash
npm install
npm run dev
```

## 구조

- `src/App.jsx`: 로딩, 홈, 카테고리 화면과 인터랙션
- `src/styles.css`: 웹폰트, 레이아웃, 모션, 반응형 스타일
- `src/projects.js`: 최신순 작업물 데이터 연결 지점
- `.github/workflows/deploy.yml`: main push 기반 GitHub Pages 배포

실제 이미지·영상은 추후 `src/projects.js`의 프로젝트 데이터에 연결합니다.
